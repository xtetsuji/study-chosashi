# 調査士法・逆三角形マップ

土地家屋調査士制度の主体を固定座標へ配置し、論点ごとに実際に使う経路だけを強調する試作教材です。

## 扱う内容

- 調査士となる資格を有する者による新規登録
- 事務所を他の法務局・地方法務局の管轄区域へ移転する場合の所属会変更
- 申請と同時に行う入会手続
- 所属会変更時の旧所属会への届出と、変更登録時の入退会
- 各場面の手続を一枚へ重ねた暗記用の完成図
- 登録または登録拒否をした場合の連合会から申請者への書面通知
- 所属会変更以外の登録事項変更
- 必要的な登録取消しと、連合会による官報公告
- 裁量的な登録取消し、登録審査会、理由付き書面通知
- 登録拒否・登録取消しに対する法務大臣への審査請求
- 法務大臣による連合会の登録事務の監督
- 調査士会から法務大臣への報告義務
- 調査士会と連合会の会則認可経路の比較
- 調査士会による注意・勧告と法務局長等への報告
- 登録等に伴うものを除く入退会に関する調査士会から法務局長等への通知
- 調査士と調査士法人に対する懲戒、聴聞、処分後の通知、官報公告
- 懲戒手続開始時の連合会への通告と登録取消しの制限
- 何人でもできる違反事実の通知と、法務局長等による受理・調査
- 調査士法人の設立登記による成立と、成立後の調査士会・連合会への届出
- 調査士法人の定款変更・解散・合併に関する登記と届出
- 調査士法人の解散・清算を監督する裁判所と法務大臣の関係

収録状況と今後見つかった追加候補は `SCENARIOS.md` で管理します。

## 根拠

- 土地家屋調査士法第8条から第19条、第30条から第34条、第39条、第39条の3、第39条の4、第40条、第42条から第46条、第49条、第52条、第55条、第56条、第59条、第62条
- 土地家屋調査士法施行規則第32条から第43条
- 組合等登記令
- e-Gov法令検索で2026年8月16日に確認

## 操作

`index.html` をブラウザで開き、学習する論点を選んで「一つ進む」を押します。

## 論点の追加

論点ごとの表示名、根拠条文、ノード表示、段階説明、完成図は `scenarios.js` にまとめています。
画面側のHTMLや進行処理を変更せず、同じ図形文法で表せる論点を追加できます。
一部の結果でだけ使う矢印は `routeConditions` に条件文を持たせ、通常の経路と異なる色・線種・表示文で描画します。

## ファイル

- `index.html`: 教材本文とSVG
- `style.css`: レイアウト、強調表示、アニメーション
- `scenarios.js`: 論点ごとの表示内容と段階データ
- `app.js`: 論点選択と段階の共通処理
- `SCENARIOS.md`: 収録済み・追加予定の論点一覧
