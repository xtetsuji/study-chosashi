# 登録経路・逆三角形マップ

土地家屋調査士制度の主体を固定座標へ配置し、新規登録と所属会変更で実際に使う経路だけを強調する試作教材です。

## 扱う内容

- 調査士となる資格を有する者による新規登録
- 事務所を他の法務局・地方法務局の管轄区域へ移転する場合の所属会変更
- 申請と同時に行う入会手続
- 所属会変更時の旧所属会への届出と、変更登録時の入退会
- 各場面の手続を一枚へ重ねた暗記用の完成図

登録拒否、審査請求、調査士法人の登録は扱いません。

## 根拠

- 土地家屋調査士法第8条、第9条、第13条、第52条
- e-Gov法令検索で2026年8月15日に確認

## 操作

`index.html` をブラウザで開き、「新規登録」または「所属会変更」を選んで「一つ進む」を押します。

## ファイル

- `index.html`: 教材本文とSVG
- `style.css`: レイアウト、強調表示、アニメーション
- `app.js`: 場面と段階の切替
