# シナリオ収録状況

土地家屋調査士法の主体・相手方・動詞・経由先を逆三角形図で比較するための収録一覧です。

## 収録済み

| 分野 | シナリオ | 根拠条文 |
| --- | --- | --- |
| 登録 | 新規登録と入会手続 | 8条、9条、52条1項・2項 |
| 登録 | 所属会変更と新旧会の入退会 | 13条、52条1項から3項 |
| 登録 | 登録・登録拒否の書面通知 | 11条、13条4項 |
| 登録 | 所属会変更以外の登録事項変更 | 14条 |
| 調査士会 | 所属会員の違反に関する法務大臣への報告 | 55条 |
| 懲戒 | 調査士に対する懲戒・処分後の通知・官報公告 | 42条、44条、46条、施行規則36条 |
| 懲戒 | 調査士法人に対する懲戒・処分後の通知・官報公告 | 43条、44条、46条、施行規則36条 |

## 追加予定

| 分野 | シナリオ候補 | 表現上の検討事項 |
| --- | --- | --- |
| 登録 | 必要的な登録取消し | 取消事由、届出者、所属会経由、官報公告を分ける |
| 登録 | 裁量的な登録取消し | 登録審査会を連合会内部の拡大表示として扱う |
| 法人 | 調査士法人に関する手続 | 下頂点を法人に切り替え、個人との効果の違いを示す |
| 懲戒 | 懲戒手続の開始と登録取消しの制限 | 法務大臣から連合会への手続開始通知と、手続終了までの制限を段階表示する |
| 懲戒 | 違反事実の通告・調査 | 誰でもできる通告と、法務局長等への権限委任をクローズアップする |
