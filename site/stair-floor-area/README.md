# 階段床面積・算入ビジュアライザー

階段部分を上階床面積へ算入するか、吹抜けと階段脇の区画から判断する
静的教材のプロトタイプです。

## 確認方法

`index.html` を直接開くか、リポジトリ全体の公開用ファイルを生成して確認します。

```bash
pnpm --dir period-flashcards build
node scripts/build-site.mjs
python3 -m http.server 4173 --directory dist
```

公開用ファイルでは `http://localhost:4173/stair-floor-area/` から開けます。

## ファイル

- `index.html`: 教材の画面、法令・事務連絡の出典
- `style.css`: 階段平面の模式図、算入範囲のアニメーション、レスポンシブ表示
- `app.js`: 6事例のデータ、回答判定、表示処理

## プロトタイプの対象

令和4年6月23日法務省民事局民事第二課事務連絡
「建物の床面積の算定における階段部分の上階床面積への算入等の取扱いについて」
別紙1の6事例を対象にしています。

- 吹抜けがなく、両面が壁
- 吹抜けがなく、片面が腰壁手すり
- 吹抜けがなく、片面が格子手すり
- 吹抜けに接し、両面が壁
- 吹抜けに接し、片面が腰壁手すり
- 吹抜けに接し、片面が格子手すり

事務連絡の図や試験問題を転載せず、判断条件を比較するための独自の模式図として
再構成しています。

## 学習モード

- 観察モード: 吹抜けの有無と、階段脇の壁・腰壁手すり・格子手すりを自由に切り替え、
  算入範囲と判定理由の変化を即時に確認する
- クイズモード: 6事例について「算入する・しない」を回答してから、算入範囲と判断過程を確認する

観察モードも、反対側には壁があるという事務連絡の6類型の範囲に限定しています。
