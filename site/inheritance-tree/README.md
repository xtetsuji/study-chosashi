# 相続ツリー・ラボ

家族に起きた出来事を時系列で追い、相続開始時の法定相続人と法定相続分を学ぶ
静的教材のプロトタイプです。

## 確認方法

`index.html` を直接開くか、リポジトリ全体の公開用ファイルを生成して確認します。

```bash
pnpm --dir period-flashcards build
node scripts/build-site.mjs
python3 -m http.server 4173 --directory dist
```

公開用ファイルでは `http://localhost:4173/inheritance-tree/` から開けます。

## ファイル

- `index.html`: 教材の画面と法令出典
- `style.css`: 家系図、回答結果、レスポンシブ表示
- `app.js`: シナリオデータ、時系列、回答判定、表示処理

## プロトタイプの対象

- 配偶者と子
- 子の代襲・再代襲
- 兄弟姉妹の代襲と再代襲不可
- 全血・半血兄弟姉妹
- 養子縁組前後に生まれた養子の子
- 廃除された子と孫の代襲
- 相続放棄と代襲の不発生
- 子の相続放棄による直系尊属への順位移動
- 孫が被相続人の養子でもある場合の二重資格
- 相続開始時の胎児による代襲
- 相続欠格となった子と孫の代襲

遺言、遺留分、特別受益、寄与分、遺産分割、相続税などは
対象外です。

相続開始時は、家系図の人物カードまたは回答欄のチェックボックスから相続人候補を
選択できます。人物カードはクリック・タップのほか、フォーカスしてEnterキーまたは
Spaceキーでも選択・解除できます。

## 法令確認

- 根拠: 民法第727条、第886条から第892条まで、第900条、第901条、第938条、第939条
- 出典: e-Gov法令検索「民法」
- 確認基準日: 2026年8月4日

個別事案への法的助言ではなく、現行法の一般則を単純化した試験学習用教材です。

## 過去問論点との対応

平成27年度から令和7年度までの第1問から第3問を確認し、法定相続人と法定相続分に
直接関係する未収録論点を、問題文を転載しない独自事例として追加しています。

- 平成30年度第3問: 相続欠格と代襲相続
- 令和3年度第3問: 孫が養子でもある場合の二重資格
- 令和6年度第3問: 相続開始時に胎児である代襲者

遺言、遺産分割、限定承認など、法定相続人・法定相続分の家系図だけでは扱いにくい
論点は、この教材の対象外として追加していません。
