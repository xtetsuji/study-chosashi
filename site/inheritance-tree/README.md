# 相続ツリー・ラボ

家族に起きた出来事を時系列で追い、相続開始時の法定相続人と法定相続分を学ぶ
静的教材のプロトタイプです。

## 確認方法

`index.html` を直接開くか、リポジトリ全体の公開用ファイルを生成して確認します。

```bash
pnpm --dir period-flashcards build
node scripts/build-site.mjs
python3 -m http.server 4173 --directory dist
```

公開用ファイルでは `http://localhost:4173/inheritance-tree/` から開けます。

## ファイル

- `index.html`: 教材の画面と法令出典
- `style.css`: 家系図、回答結果、レスポンシブ表示
- `app.js`: シナリオデータ、時系列、回答判定、表示処理

## プロトタイプの対象

- 配偶者と子
- 子の代襲・再代襲
- 兄弟姉妹の代襲と再代襲不可
- 全血・半血兄弟姉妹
- 養子縁組前後に生まれた養子の子

遺言、遺留分、相続放棄、欠格、廃除、特別受益、寄与分、遺産分割、相続税などは
対象外です。

相続開始時は、家系図の人物カードまたは回答欄のチェックボックスから相続人候補を
選択できます。人物カードはクリック・タップのほか、フォーカスしてEnterキーまたは
Spaceキーでも選択・解除できます。

## 法令確認

- 根拠: 民法第727条、第887条から第890条まで、第900条、第901条
- 出典: e-Gov法令検索「民法」
- 確認基準日: 2026年8月3日

個別事案への法的助言ではなく、現行法の一般則を単純化した試験学習用教材です。
