# ダストシュート床面積ビジュアライザー

ダストシュートまたは煙突の位置を建物の内外へ動かし、各階床面積への算入範囲を学ぶ
静的教材のプロトタイプです。

## 確認方法

`index.html` を直接開くか、リポジトリ全体の公開用ファイルを生成して確認します。

```bash
pnpm --dir period-flashcards build
node scripts/build-site.mjs
python3 -m http.server 4173 --directory dist
```

公開用ファイルでは `http://localhost:4173/dust-chute-floor-area/` から開けます。

## ファイル

- `index.html`: 教材画面、準則と過去問の出典
- `style.css`: 建物断面、各階平面、位置移動のアニメーション
- `app.js`: 設備・位置の切替、ドラッグ操作、判定文、3状態の連続再生

断面図の設備本体はマウスまたはタッチで左右へドラッグでき、離すと3状態の最寄りの位置へ
吸着します。キーボードで設備にフォーカスし、左右矢印、Home、Endキーでも移動できます。

## 対象とする取扱い

不動産登記事務取扱手続準則第82条第10号に基づき、次の3状態を比較します。

- ダストシュート・煙突の全部が建物内部: 設備部分の全部を各階床面積に算入
- 建物内部にある設備の一部が外側へ及ぶ: 張出部分を含む設備全体を各階床面積に算入
- 設備の全部が建物外側: 各階床面積に不算入

令和4年度土地家屋調査士試験午後第12問の出題論点を含みます。公式問題の図は転載せず、
位置関係を比較する独自の模式図として再構成しています。
