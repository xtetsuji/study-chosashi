# 筆界特定・情報収束ダイヤモンド

筆界特定制度の登場人物を制度上のロールとして固定配置し、論点ごとの情報の向きを一手ずつ確認する教材です。

## 固定配置

- 上：筆界特定登記官
- 左：筆界調査委員
- 右：関係人
- 下：申請人

土地家屋調査士は固定ノードにせず、申請人の代理人または筆界調査委員になり得る専門家という属性で表示します。筆界調査委員を補助する法務局職員も独立ノードにはしていません。

## 収録ストーリー

1. 制度全体の基本フロー
2. 関係人の手続保障
3. 土地家屋調査士の二つのロールと同一事件での指定除外
4. 筆界特定後の通知・公告
5. 筆界確定訴訟との独立ルート
6. 手続費用の予納と却下
7. 共有者を例にした申請人と関係人の分かれ方
8. 調査権限と情報収集先

## 根拠

- 不動産登記法第127条、第131条から第140条、第142条から第148条
- 土地家屋調査士法第3条第1項第4号
- e-Gov法令検索および法務局「筆界特定手続の流れ」で2026年8月16日に確認

## 操作

`index.html` をブラウザで開き、ストーリーを選択して「一つ進む」「一つ戻る」で流れを確認します。主要操作はキーボードでも行えます。
選択中のストーリーと段階は `?story=court-route&step=2` のようにURLへ反映され、再読み込みやブラウザの戻る・進むでも復元できます。

## ファイル

- `index.html`: 教材本文と固定配置SVG
- `style.css`: レイアウト、段階点灯、レスポンシブ表示
- `scenarios.js`: ストーリーごとの段階データ
- `url-state.js`: URLへのストーリー・段階の保存と復元
- `app.js`: ストーリー選択と段階表示の共通処理
