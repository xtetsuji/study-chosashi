# 土地家屋調査士の学習ツール

このリポジトリは、xtetsuji が土地家屋調査士試験の受験勉強をする上で、
学習に使える小さめのツールを各種管理する場所です。

## 収録内容

- `period-flashcards/`: 保存期間などの数字知識を反復するフラッシュカード
- `site/civil-rights-transitions/`: 不動産の二重譲渡と登記の関係を動かして学ぶ試作教材
- `site/inheritance-tree/`: 法定相続人と法定相続分を家系図で学ぶ試作教材
- `site/stair-floor-area/`: 階段部分の上階床面積への算入を図で学ぶ試作教材
- `site/dust-chute-floor-area/`: ダストシュート・煙突の各階床面積への算入を学ぶ試作教材
- `site/`: GitHub Pagesで公開する学習コンテンツの入口と公開計画

## GitHub Pagesでの公開構想

小さな学習アプリを一つずつ追加し、`site/` を入口とする静的サイトとして公開します。
現在は期間フラッシュカードと、民法の権利変動を時系列とアニメーションで理解する
試作教材を収録しています。

詳しい候補、優先順位、ディレクトリ構成、公開手順は
[`site/README.md`](site/README.md) を参照してください。

新しい教材の追加方法、デザイン方針、完了条件は
[`DEVELOPMENT.md`](DEVELOPMENT.md) を参照してください。
